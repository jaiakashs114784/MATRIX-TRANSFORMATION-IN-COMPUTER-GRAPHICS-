SECTION 01 — FUNDAMENTALS
02

WHAT IS A MATRIX
TRANSFORMATION?

A matrix transformation is a mathematical rule that uses a matrix to change every point of an object in a coordinate system.

  • PChanges position — where the object sits
  • ↻Changes orientation — which way it faces
  • ⤢Changes size — how large it appears
  • ◇Changes shape — slants, mirrors, stretches
SECTION 01 — FUNDAMENTALS
03

WHY USE MATRICES?

  • ∑Compact — an entire transformation is one small table of numbers
  • ⚡Fast — one matrix × vector multiply moves a whole 3D model
  • ×Composable — multiply matrices to chain transformations
  • ⚙Universal — the same math drives games, CAD, vision & robot arms
SECTION 02 — GEOMETRY BASICS
04

COORDINATE SYSTEMS

Every transformation is described relative to a coordinate frame — a reference point plus directions.

  • ⊙Origin — the fixed reference point (0, 0, 0)
  • XAxes X, Y, Z — three perpendicular directions
  • ⌖A point = its distances along each axis: p = (x, y, z)
  • ⛭Robots attach a frame to every link & joint — motion = frame-to-frame math
SECTION 02 — THE BASIC TRANSFORMATIONS
05

TRANSLATION

Translation slides every point by the same offset — it moves an object without rotating or resizing it.

1  0  tx
0  1  ty
0  0  1
x′ = x + tx  ·  y′ = y + ty

tx, ty = shift along X / Y · the 1s keep the shape unchanged · bottom row enables matrix multiplication

SECTION 02 — THE BASIC TRANSFORMATIONS
06

ROTATION

Rotation spins the object around the origin by an angle θ (theta). Distances from the origin stay fixed.

cos θ  −sin θ
sin θ  cos θ
x′ = x·cosθ − y·sinθ
y′ = x·sinθ + y·cosθ

θ = rotation angle · for 3D, one such matrix is used per axis (X, Y, Z)

SECTION 02 — THE BASIC TRANSFORMATIONS
07

SCALING

Scaling multiplies each coordinate by a factor — it resizes the object, stretching or shrinking it from the origin.

sx  0
0  sy
  • >sx > 1 → enlarge  ·  sx < 1 → shrink
  • =sx = sy = 1 → identity, nothing changes
  • ≠sx ≠ sy → non-uniform stretch (shape distorts)
SECTION 02 — THE BASIC TRANSFORMATIONS
08

BEYOND THE BIG THREE

Two more matrix transforms appear constantly in graphics and vision:

  • ⇋Reflection — mirror the object across an axis (flip X or Y)
  • ⧩Shearing — push points sideways, proportional to height → slanted shapes

Both are just 2×2 matrices with different number patterns.

SECTION 03 — ROBOTICS CORE
09

HOMOGENEOUS
TRANSFORMATION

The single 4×4 matrix used in all 3D graphics and robotics. It packs rotation + translation into one operation → a complete robot pose (position + orientation).

3×3 BLOCK

top-left r11…r33 = ROTATION of the frame

LAST COLUMN

tx ty tz = TRANSLATION of the origin

r11 r12 r13 tx
r21 r22 r23 ty
r31 r32 r33 tz
0   0   0   1
SECTION 03 — ROBOTICS CORE
10

COMBINING TRANSFORMS

Matrix multiplication chains transforms into one matrix. A robot arm's full motion = one product.

T = T₁ × T₂ × T₃
  • ↧Read right-to-left: T₁ acts first, then T₂, then T₃
  • ⚠Order matters — matrix multiplication is not commutative:  T₁ × T₂ ≠ T₂ × T₁
rotate-then-move ≠ move-then-rotate → different final pose
SECTION 04 — WORKED EXAMPLE
11

WORKED EXAMPLE

Translate point p = (2, 1) by tx = 3, ty = 2:

1 0 3  ·  [2]
0 1 2     [1]
0 0 1     [1]
x′ = 1·2 + 0·1 + 3·1 = 5
y′ = 0·2 + 1·1 + 2·1 = 3
p′ = ( 5 , 3 ) ✓
SECTION 05 — ROBOTICS APPLICATION
12

PICK-&-PLACE ROBOT

  • ⌖Vision locates the object → its position is a point in the camera frame
  • TA homogeneous matrix converts it into the robot's base frame
  • ⛭Joint transforms compute the end-effector pose needed to reach it
  • ✋Robot moves → picks → transforms to target → places

Every "where is it / where must I go" question in robotics is a matrix transformation.
